🚀 READY TO RUN
════════════════════════════════════════════════════════════════════════════════

To start development:

1. Install Frontend:
   cd client && npm install

2. Install Backend:
   cd ../server && npm install

3. Run Frontend (Terminal 1):
   cd client && npm run dev
   → http://localhost:3000

4. Run Backend (Terminal 2):
   cd server && npm run dev
   → http://localhost:5000

5. Start MongoDB (Terminal 3):
   mongod
   → mongodb://localhost:27017/mobidrag_portal
